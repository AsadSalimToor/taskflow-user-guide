# 1. Introduction

## 1.1 About TaskFlow

TaskFlow is a fictional web-based project management application designed to help organisations plan projects, assign tasks, monitor progress and collaborate with team members.

The application provides a centralised workspace where users can manage project activities, track deadlines and monitor workloads.

This guide explains the main features of TaskFlow and provides step-by-step instructions for performing common tasks.

## 1.2 Intended Audience

This guide is intended for:

- Project Managers
- Team Leaders
- Project Coordinators
- Team Members
- System Administrators

## 1.3 Key Features

TaskFlow provides the following functionality:

- Centralised project management.
- Task creation and assignment.
- Project progress monitoring.
- Team member management.
- Role-based access permissions.
- Task status tracking.
- Project activity monitoring.

# 2. Getting Started

## 2.1 System Requirements

TaskFlow is designed to operate through a modern web browser.

Recommended environment:

- Google Chrome (current supported version).
- Microsoft Edge (current supported version).
- Mozilla Firefox (current supported version).
- Stable internet connection.
- Desktop or laptop computer.

## 2.2 Accessing TaskFlow

To access the application:

1. Open a supported web browser.
2. Enter the TaskFlow application URL.
3. Wait for the login page to appear.
4. Enter your registered email address.
5. Enter your password.
6. Click **Sign In**.

After successful authentication, the TaskFlow Dashboard appears.

**Note:** Access to TaskFlow requires an active user account created by the organisation's administrator.

## 2.3 Signing Out

To sign out of TaskFlow:

1. Click your profile icon in the upper-right corner.
2. Select **Sign Out**.
3. The application returns to the login page.

# 4. Managing Projects

The Projects module allows authorised users to create, view and manage projects.

## 4.1 Viewing Projects

To view available projects:

1. Select **Projects** from the navigation menu.
2. The Projects page displays the projects accessible to you.
3. Review the project name, description, status and assigned project manager.
4. Select a project to view its details.

## 4.2 Creating a Project

Users with the appropriate permissions can create new projects.

To create a project:

1. Navigate to **Projects**.
2. Click **Create Project**.
3. Enter the project name.
4. Provide a project description.
5. Select the project start date.
6. Enter the expected completion date.
7. Assign a project manager.
8. Click **Save**.

The application creates the project and adds it to the Projects list.

**Important:** Ensure that the project start and completion dates are accurate before saving.

## 4.3 Updating Project Details

To update an existing project:

1. Open the **Projects** module.
2. Select the required project.
3. Click **Edit Project**.
4. Modify the required information.
5. Click **Save Changes**.

The updated information is displayed on the project details page.

---

# 5. Managing Tasks

The Tasks module allows users to create, assign and monitor individual work items.

## 5.1 Creating a Task

To create a new task:

1. Open the required project.
2. Navigate to the **Tasks** section.
3. Click **Add Task**.
4. Enter a descriptive task title.
5. Provide a detailed task description.
6. Assign the task to a team member.
7. Set the task priority.
8. Enter the task due date.
9. Click **Save**.

The new task appears in the project's task list.

## 5.2 Assigning Tasks

To assign a task:

1. Open the required task.
2. Locate the **Assigned To** field.
3. Select a team member from the available list.
4. Click **Save Changes**.

The selected team member becomes responsible for the task.

## 5.3 Updating Task Status

TaskFlow supports the following task statuses:

| Status | Description |
|---|---|
| Not Started | Work has not yet begun. |
| In Progress | Work is currently underway. |
| On Hold | Work has been temporarily suspended. |
| Completed | The task has been finished. |

To update a task status:

1. Open the required task.
2. Locate the **Status** field.
3. Select the appropriate status.
4. Save the changes.

The updated status is reflected in the task list.

## 5.4 Setting Task Priority

Users can assign one of the following priority levels:

- Low
- Medium
- High
- Critical

Priority levels help project managers identify tasks requiring immediate attention.

# 7. User Roles and Permissions

TaskFlow uses role-based access to control which features users can access.

| Role | Permissions |
|---|---|
| Administrator | Manages users, permissions and system settings. |
| Project Manager | Creates projects, assigns tasks and monitors progress. |
| Team Leader | Manages assigned team activities and task assignments. |
| Team Member | Views assigned projects and updates personal tasks. |

Users can access only the functions permitted by their assigned roles.

**Important:** Contact your system administrator if you require additional access permissions.

# 9. Troubleshooting

The following table describes common issues and recommended actions.

| Issue | Possible Cause | Recommended Action |
|---|---|---|
| Unable to sign in | Incorrect login credentials | Verify your email address and password. |
| Project not visible | Insufficient permissions | Contact your project administrator. |
| Unable to create a task | Missing permissions | Request the appropriate access rights. |
| Changes not appearing | Changes were not saved | Repeat the update and select Save. |
| Application not loading | Network or browser issue | Check your internet connection and refresh the page. |
| Report not generated | Invalid report criteria | Review the selected project and reporting period. |

## 9.1 General Troubleshooting Guidelines

Before contacting technical support:

1. Check your internet connection.
2. Refresh the application page.
3. Verify that you are using a supported browser.
4. Confirm that you have the required permissions.
5. Record any error message displayed by the application.

If the issue persists, contact your organisation's TaskFlow administrator.

# 10. Frequently Asked Questions

**Q1. Can I access TaskFlow from different computers?**

Yes. TaskFlow is a browser-based application and can be accessed from supported computers with an internet connection and an authorised account.

**Q2. Can I create projects without administrator access?**

Project creation depends on your assigned user permissions.

**Q3. Can I assign a task to another team member?**

Users with appropriate project management or team leadership permissions can assign tasks.

**Q4. What should I do if I forget my password?**

Use the password recovery option on the login page, if enabled by your organisation. Otherwise, contact your administrator.

**Q5. Can completed tasks be updated?**

Task updates depend on the permissions and workflow rules configured by your organisation.
